📋 Overview

VPOS is a business-focused Point of Sale management system developed by Value Tech Solutions for supermarkets and retail stores in India. Shopkeepers (retail store and supermarket owners) can self-register to access the platform. Other user roles (Admin, Service Agent, Manager) are created by authorized personnel only.

This Privacy Policy describes what information VPOS collects, how it is used, stored, and protected. By using any VPOS application (Admin, Billing, or Billing Offline), you agree to the practices described in this policy.

☁️ Data Storage & Security

Cloud Infrastructure

All data is stored on Google Firebase (Cloud Firestore and Firebase Storage), hosted on Google's secure cloud infrastructure in the asia-south1 (Mumbai, India) region. This ensures data sovereignty and compliance with Indian data localization requirements.

Encryption

  • In Transit: All data transmitted between apps and servers is encrypted using TLS/SSL
  • At Rest: Data stored in Firestore and Firebase Storage is encrypted at rest using AES-256 encryption
  • QR Codes: Device QR codes use AES-256-CBC encryption for secure device registration

Access Control

  • Firebase Authentication with role-based custom security claims (Admin, Service Agent, Shopkeeper, Manager)
  • Each shopkeeper can only access their own data — strict data isolation enforced by Firestore security rules
  • Service agents have limited read access for support purposes only
  • Managers can only access data from their assigned branches
  • Aadhaar ID numbers, where optionally provided, are stored in a restricted Firestore collection accessible only to authorized administrators

Security Measures

  • Firebase App Check to prevent unauthorized API access
  • Firestore Security Rules to enforce role-based access control
  • Regular security audits and vulnerability assessments
  • Audit logs for tracking sensitive operations
  • Two-factor authentication (2FA) available for admin accounts

🔄 Data Retention

VPOS retains data for specific periods based on business requirements, legal obligations, and user preferences.

Retention Periods Table

Data Type Retention Period Purpose
Active Account Data Indefinite (while active) Operational use
Deactivated Account Data 90 days Allow reactivation period
Scheduled Deletion Accounts 15 days Cancellation grace period
Sales & Billing Records Minimum 3 years Tax compliance (Indian law)
Product Images (when disabled) 0-365 days (configurable) Flexible cleanup
Audit Logs 90 days Security monitoring
Activity Logs 90 days System tracking
Deleted User Backups 90 days Recovery and audit trail
Customer Information Indefinite (shopkeeper managed) Business operations

Account Deletion Process

When an account is scheduled for deletion:

  1. 15-day grace period: Account marked for deletion but remains active
  2. Cancellation option: Admin can cancel deletion during grace period
  3. Permanent deletion: After 15 days, account and all associated data permanently deleted
  4. Backup retention: Deleted user information backed up for 90 days for recovery and audit purposes

Custom Retention Periods

Need Different Retention Periods? If your business requires custom retention periods (e.g., longer retention for auditing, shorter cleanup cycles), please contact our support team at support@vposindia.com or call 090190 69884. We will work with you to configure appropriate settings.

👤 Your Rights

Access Your Data

You have the right to access your personal information stored in VPOS. Shopkeepers can view their data through the VPOS Admin application. For data export requests, contact our support team.

Update Your Data

Shopkeepers can update their profile information directly in the VPOS Admin application. Service agents can assist with updates if needed. Some fields (like customer type) may require admin approval.

Delete Your Data

You can request account deletion by contacting our support team. Deletion follows a 15-day grace period as described in our Terms & Conditions. Note that some data (like transaction records) must be retained for 3 years to comply with Indian tax laws.

Export Your Data

You can export your business data (inventory, sales reports, customer lists) directly from the VPOS Admin application. For comprehensive data exports, contact our support team.

Withdraw Consent

For data collected with consent (like customer information during billing), you can stop collection at any time. Previously collected data may be retained as required by law or business operations.

Object to Processing

If you believe your data is being processed incorrectly or without proper authorization, contact our support team to file a complaint.
